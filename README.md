# Think Tastic Tests

Build a complete, professional, functional and mobile-responsive website for my BCA mini project.



PROJECT TITLE: Online Quiz Website

WEBSITE NAME: QuizNova — Smart Quiz Platform

DEVELOPED BY: Sonal Gayakwad

PROJECT CATEGORY: Student and Personal Projects



IMPORTANT: Follow all the requirements of my college assignment PDF. This project must include a polished website, working interactions, responsive design, testing and features that I can explain during my practical demonstration.



1. DESIGN AND APPEARANCE



- Create a premium, modern educational website.

- Use a beautiful light background with purple and blue accents.

- Add elegant cards, smooth animations, subtle shadows and modern typography.

- Make the website look professional, not like a basic template.

- Ensure the design works perfectly on mobile, tablet and desktop.

- Use suitable icons and illustrations.



2. HOME PAGE



- Website logo and name: QuizNova.

- Navigation menu: Home, Categories, About, Contact.

- Hero heading: "Challenge Your Knowledge".

- Short introduction explaining the purpose of the quiz platform.

- A prominent "Start Quiz" button.

- Display sample statistics about available categories, quizzes and questions.

- Add an About section explaining the website.

- Add a "How It Works" section with simple steps.

- Add a section showcasing popular quiz categories.



3. QUIZ CATEGORIES

   Create attractive category cards for:



- Artificial Intelligence

- Computer Science

- General Knowledge

- Web Development

- Programming Fundamentals



Each category should have an icon, description, difficulty selection and Start Quiz button.



4. INTERACTIVE QUIZ



- Display one multiple-choice question at a time.

- Provide four answer options for each question.

- Include Previous and Next buttons.

- Display the question number and progress bar.

- Add a working countdown timer.

- Include a Submit Quiz button.

- Ask for confirmation before early submission.

- Allow users to change their selected answers before submitting.

- Prevent duplicate submissions.

- Use original sample questions with verified correct answers.

- Provide at least five questions per category.

- Shuffle questions when a new attempt begins, where practical.

- Reset the timer and answers when restarting a quiz.



5. RESULTS PAGE

   After quiz submission, display:



- Total questions.

- Correct answers.

- Incorrect answers.

- Final score.

- Percentage.

- Performance feedback.

- Review Answers section showing the user's answer and the correct answer.

- Retake Quiz button.

- Back to Home button.



Ensure the scoring calculation is accurate and all result buttons work.



6. SEARCH AND FILTERS



- Allow users to select a quiz category.

- Add difficulty filters: Easy, Medium and Hard.

- Add a search field to find quiz categories.

- Make these features functional.

- Display a friendly message when no results match.



7. CONTACT SECTION



- Create a contact form containing:

  Name, Email and Message.

- Validate all required fields.

- Display a success message after valid submission.

- Do not falsely claim that messages are emailed or stored in a database.

- Use fictional sample contact details if needed.

- Do not display any real personal phone number or address.



8. FOOTER AND DEVELOPER CREDIT

   This requirement is essential.



At the bottom of every main page, create a clean and professional footer containing:



- QuizNova logo and name.

- Quick navigation links.

- Short project description.

- Contact section link.

- Copyright notice.

- A clearly visible developer credit in elegant typography:



"Developed by Sonal Gayakwad"



Make this developer credit easy to notice but keep it professional. It must appear at the very bottom of the website and remain visible when the user scrolls to the footer.



9. TECHNICAL REQUIREMENTS



- Use React, TypeScript and Tailwind CSS if supported.

- Organize the code into reusable components.

- Use local sample data for quiz questions.

- A real database, login system or authentication is not required.

- Use localStorage only if useful for saving non-sensitive quiz progress or results.

- Ensure navigation, buttons, quiz logic, timer, scoring, search, filters and form validation work.

- Do not leave placeholder buttons or broken links.

- Add appropriate loading, empty and error states where necessary.



10. TESTING AND QUALITY CHECK

    Before completing the project, test:



- Home page navigation.

- Starting and completing a quiz.

- Selecting and changing answers.

- Previous and Next buttons.

- Countdown timer.

- Quiz submission.

- Score and percentage calculation.

- Answer review.

- Retaking a quiz.

- Search and category filters.

- Contact form validation.

- Mobile and desktop responsiveness.



Fix any errors found during testing.
